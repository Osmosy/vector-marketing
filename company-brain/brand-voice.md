# Brand Voice

**Прямой, технически-грамотный, без хайпа. Говорим как практики, которые работали в полях.**

## Базовые принципы

- Короткие предложения, простой язык
- Конкретные цифры, реальные данные, измеримые результаты
- Активный залог, не пассивный
- Уважаем время и интеллект читателя
- Лучше недообещать и перевыполнить, чем наоборот

## Запрещённые формулировки (никогда не использовать)

- "leveraging" / "используя потенциал"
- "synergy" / "синергетический эффект"
- "game-changer" / "меняет правила игры"
- "инновационный подход"
- "в современном мире" / "в эпоху цифровизации"
- "комплексное решение"
- "передовые технологии" (без конкретики)
- "AI-powered" (если не можем доказать конкретную возможность)
- "целостный подход"
- "бесшовная интеграция"
- "лучший в своём классе"

## Стиль по каналам

| Канал | Тон |
|-------|-----|
| Telegram | Самый острый, concise, high-signal. Зови вещи своими именами |
| VC.ru / Хабр | Чуть развёрнутее, но плотно. Один конкретный пример на статью |
| Email / рассылка | Тёплый + прямой, value-first. Без продажных вступлений |
| Лендинг | Чёткие выгоды, низкий барьер, уверенно без высокомерия |
| Презентация / КП | Точно, структурированно, evidence-heavy |
| Авито / маркетплейсы | Простой, конкретный, продаваемый. Без корпоративного сленга |

## Тест "Я бы это опубликовал?"

Каждый драфт должен проходить этот фильтр. Если реальный маркетолог/клиент закатил бы глаза — переписать.

## Примеры хороших формулировок

- "Снизили стоимость заявки с 2 800 ₽ до 640 ₽ за 3 недели на Директе"
- "Конверсия лендинга выросла с 3.2% до 7.1% после пересборки первого экрана"
- "Если ваша CRM не показывает источник заявки по UTM-метке — у вас проблема с данными, а не с рекламой"

## Примеры плохих формулировок (не повторять)

- "Мы помогаем бизнесу эффективно развиваться в цифровой среде"
- "Используем передовые технологии для достижения результатов"
- "Комплексный подход к маркетингу вашего бизнеса"
