# Wordstat для рынка РФ: чем пользоваться и чего в нём нет

## Что Wordstat показывает, а что нет

- **Показывает:** сколько раз фразу вводили в Яндекс за последние 30 дней, как менялся
  интерес по месяцам/неделям/дням, из каких регионов идут запросы, какие фразы ищут рядом.
- **Не показывает:** конверсию, готовность платить, конкурентов в выдаче, стоимость клика.
  Это разные слои: спрос (Wordstat) → конкуренция и ставки (Директ, Метрика) → экономика
  (свои CRM-данные).

Wordstat — про **спрос**, а не про «потенциал продаж». Фраза с частотой 10 000 может
давать хуже заявки, чем фраза с 300: сравнение делается по кластерам и интенту, а не по
абсолютной частоте.

## Wordstat vs прогноз бюджета Директа

| Что нужно | Инструмент |
|-----------|-----------|
| Какие фразы существуют, насколько частотны, где и когда ищут | **Wordstat** (этот навык) |
| Сколько будет стоить клик, сколько показов и визитов за бюджет | прогноз бюджета в интерфейсе Директа / API Директа |
| Фактический спрос по своим посетителям | Метрика (поисковые фразы, цели) |

Никогда не подменяйте одно другим: частотность Wordstat ≠ показы в Директе (учитываются
ставки, гео, устройства, минус-слова и конкуренция).

## Seed-фразы: откуда брать

API принимает **фразу**, не сайт. «Парсер, куда кидаешь сайт» — это связка из двух шагов,
и второй шаг (получить seed из сайта) делается отдельно: карта сайта, заголовки H1/H2,
карточки товаров, категории, страницы услуг.

Слои seed, которые дают ровное ядро:

1. **Категория/продукт** — «купить кофе в зернах», «кофе оптом».
2. **Проблема/сценарий** — «кофе горчит что делать», «как хранить зерна».
3. **Аудитория/роль** — «кофе для офиса», «кофе для кофейни».
4. **Гео** — «кофе с доставкой спб».
5. **Бренд/конкурент** — включать только чтобы понять навигационный спрос, в SEO-ядро
   обычно не берётся.
6. **Синонимы и жаргон отрасли** — «арабика», «робуста», «зеленое зерно».

## Сезонность и календарь

`dynamics --period monthly` по главным фразам кластера даёт форму спроса. Практика:

- пик → туда двигаем бюджет, публикации и акции;
- спад → не поднимать ставки «чтобы вернуть трафик»: он падает у всех;
- год-к-году (сравнить два одинаковых месяца) — честнее месячного сравнения подряд.

## Гео и affinity index

`affinityIndex` > 1 означает, что в регионе фраза востребована сильнее, чем в среднем по
стране. Работает для локальных лендингов, региональных кампаний и Авито: сначала регионы
с высоким индексом, потом остальные. `--regions 225` — вся Россия; после
`regions-tree` фильтр можно сузить до конкретных ID.

## Гигиена данных

- Всегда фиксируйте, с какими `regions`/`devices` собран прогон: частоты с фильтром и без
  него несравнимы.
- Храните сырой JSON прогона (он и есть первоисточник для будущих брифов), а таблицы
  собирайте из него — не наоборот.
- Повторяйте сбор раз в месяц-квартал: сезонность и новые формулировки меняют ядро,
  а старый ядро-файл незаметно устаревает.
- Частоту фразы легко переоценить: в Wordstat учитываются все запросы, включая
  информационные без коммерческого намерения. Размечайте интент до того, как обещать
  клиенту трафик.
