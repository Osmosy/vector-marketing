# Пример полной кампании — день за днём

## Цель

30+ квалифицированных заявок за 30 дней на консультацию по настройке Яндекс Директа через мультиканальный контент + лёгкий paid + outbound.

## День 1 — Research

**Человек → Osmosy:**
"Проанализируй топ-конкурентов в нише настройки Директа: что пишут на VC, Telegram, что показывается в ChatGPT/Perplexity при запросе про настройку Директа. Какие углы работают?"

**Osmosy → delegate_task → market-research:**
- Конкуренты на VC: [список + углы]
- Telegram-каналы: [что работает]
- ChatGPT/Perplexity: [кто цитируется, какие пробелы]
- Рекомендация: 3 угла для контента

## День 1-2 — SEO + AEO + GEO бриф + Контент

**Osmosy → delegate_task → seo:**
- Ключевые слова: [семантика]
- Вопросы для AEO: [что спрашивают в поиске и AI]
- GEO citation opportunities: [где можно получить упоминания]
- Структура статей: [extractable answer blocks]

**Osmosy → delegate_task → content (параллельно с seo):**
- VC статья: "Как снизить CPL на Директе с 3000₽ до 600₽"
- Telegram пост: выжимка из статьи
- Email-рассылка: value-first, 1 инсайт + 1 CTA
- Блог на сайте: SEO + AEO + GEO structured

## День 2-3 — PR + Outbound

**Osmosy → delegate_task → pr:**
- Углы для media pitch: [3 варианта]
- Цели: [отраслевые блоги, подкасты]
- GEO value: [authoritative mentions для цитируемости]

**Osmosy → delegate_task → outbound:**
- Критерии лидов: [компании, которые тратят на Директ от 50K/мес]
- Первое касание: email + LinkedIn (value-first, не продажное)
- Follow-up: 3 касания за 2 недели
- Social proof: лучшие формулировки из контент-пакета

## День 3-4 — Paid + CRO

**Osmosy → delegate_task → performance:**
- Рекламные углы из рабочего органического контента
- Варианты для Директа и VK
- Test backlog: 3 гипотезы с приоритетом

**Osmosy → delegate_task → landing-cro:**
- Варианты лендинга под трафик с Директа
- Вариант под VK
- A/B гипотезы: заголовок, CTA, первый экран
- Message match: лендинг ↔ креатив ↔ запрос

## День 4+ — Запуск и мониторинг

- Человек одобряет все внешние материалы
- Osmosy → delegate_task → analytics: расставить UTM, настроить трекинг
- Неделя 1: мониторинг CPL, CR, engagement
- Неделя 2: оценка + корректировка (performance → новые креативы, content → новые углы)
- Результаты → past-campaigns.md

## Метрики успеха

- Заявки с органики (VC + Telegram + email)
- Заявки с paid (Директ + VK)
- Заявки с outbound
- CPL по каналам
- Появление в AI-ответах (brand mentions в ChatGPT/Perplexity)
- ROMI overall
