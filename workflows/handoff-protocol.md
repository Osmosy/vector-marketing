# Handoff Protocol — передача задач между агентами

## Два режима передачи

### 1. Через Osmosy (оркестратор)

Основной режим. Osmosy делегирует агентам через delegate_task, собирает результаты, проверяет противоречия, формирует единый вывод.

```
Клиент → Osmosy
  ├── delegate_task → market-research → результат
  ├── delegate_task → seo → результат
  ├── (параллельно где возможно)
  └── сборка → проверка → клиенту
```

### 2. Прямой handoff (агент → агент)

Когда один агент закончил работу и следующему нужны конкретные данные. Используется реже, через @mention в Bot Mode или через Osmosy как релей.

```
@research → конкурентная разведка + тренды + GEO сигналы
     ↓
@seo → SEO + AEO + GEO бриф
     ↓
@content → мультиканальные драфты
     ↓
@pr → питчи + план усиления
@outbound → персонализированный outreach
@paid → рекламные креативы + test backlog
     ↓
@landing-cro → варианты лендинга под трафик
```

## Правила каждого handoff

При завершении работы агент передаёт:

1. **Артефакт** — что готово (бриф, драфт, список, отчёт)
2. **Следующий агент(ы)** — кому передать
3. **Открытые вопросы** — что нужно от человека или следующего агента
4. **Контекст** — что следующему нужно знать (не заставлять перечитывать всё)
5. **Канальные заметки** — для какого канала что написано

## Примеры handoff

### Research → SEO + Content

```
@seo @content Рыночная разведка готова.

Топ-углы на VC и Telegram: ...
Вопросы, которые люди задают ChatGPT/Perplexity: ...
Пробелы у конкурентов в GEO: ...
Рекомендую: 3 статьи под SEO + 1 под GEO citation
```

### Content → PR + Outbound + Sales

```
@pr @outbound Контент-пакет готов (anti-slop пройден).

VC статья: ...
Telegram пост: ...
Email-рассылка: ...

PR-угол: ...
Переиспользуемые формулировки для outreach: ...
Готово к вашему sign-off перед публикацией.
```

### Paid → Landing-CRO

```
@landing-cro Рабочий рекламный угол этой недели: X (из органического поста в Telegram).
Подготовь варианты лендинга под трафик с Директа и VK.
```

## Human-in-the-loop

Всегда пауза для подтверждения человеком перед:
- Публикацией контента (любой канал)
- Отправкой outreach-рассылок
- Запуском рекламных кампаний
- Отправкой pitch в медиа
- Изменением ставок/бюджета в рекламе
